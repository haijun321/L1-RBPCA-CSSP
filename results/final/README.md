# Final results

This directory is intentionally empty in `0.1.1-review-candidate`. It must contain only results regenerated from the paper-linked tagged commit after the P0 protocol and algorithm issues in `docs/PUBLICATION_SUPPLEMENT_PLAN_CN.md` are closed.

Required minimum contents:

- `raw/` with one file per dataset/repeat/method or a documented long table;
- `summary/` with mean, SD, CI, valid-run count and failure count;
- `configs/` with immutable experiment configurations;
- `splits/` with split indices and corruption masks;
- `figures/` and `tables/` generated by scripts;
- `run_manifest.json` with commit, data checksum, environment and commands.

Do not copy files from `results/legacy/` into this directory without a new generation log.
